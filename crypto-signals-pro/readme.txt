تحلیل حرفه‌ای بازار ارزهای دیجیتال، ردیابی پوزیشن نهنگ‌ها و معامله‌گران بزرگ در برابر خرده‌فروش‌ها، و سیگنال خرید/فروش بر پایه تحلیل تکنیکال، فاندامنتال و آن-چین — با دسترسی قابل فروش به مشتریان.

== Description ==

Crypto Signals Pro یک سیستم تحلیل و سیگنال‌دهی ارزهای دیجیتال برای وردپرس است که:

* داده‌های قیمت و حجم را از Binance (Spot و Futures عمومی) و CoinGecko دریافت می‌کند — بدون نیاز به کلید API پولی.
* تحلیل تکنیکال کامل انجام می‌دهد: RSI، MACD، باندهای بولینژر، EMA 50/200، ATR، پیوت پوینت و روند حجم.
* پوزیشن معامله‌گران بزرگ («نهنگ‌ها») در برابر حساب‌های عمومی («خرده‌فروش‌ها») را از داده‌های عمومی Binance Futures استخراج و واگرایی هوشمند/توده را شناسایی می‌کند.
* تحلیل فاندامنتال شامل شاخص ترس و طمع، دامیننس بیت‌کوین و مومنتوم بازار را لحاظ می‌کند.
* یک موتور سیگنال وزن‌دار این سه لایه را ترکیب کرده و برچسب خرید قوی/خرید/خنثی/فروش/فروش قوی به همراه سطح اطمینان، نقطه ورود، حد ضرر و حد سود تولید می‌کند.
* نرخ موفقیت واقعی و شفاف را با پیگیری خودکار سیگنال‌های گذشته در برابر قیمت واقعی محاسبه و نمایش می‌دهد (به‌جای یک عدد تبلیغاتی ثابت).
* یک سیستم اشتراک داخلی دارد: از پنل مدیریت وردپرس برای هر مشتری اشتراک با تاریخ شروع/انقضا و دسترسی به همه یا بخشی از ارزها فعال می‌کنید.
* گزارش کامل بازار از طریق کد کوتاه `[crypto_signals]` در هر صفحه یا برگه‌ای از سایت قابل نمایش است و فقط برای کاربران دارای اشتراک فعال باز می‌شود.

**سلب مسئولیت مهم:** این افزونه یک ابزار تحلیل خودکار است، نه مشاور مالی. هیچ سیستمی نمی‌تواند نرخ موفقیت آینده را در بازار کریپتو تضمین کند. نرخ موفقیتی که این افزونه نمایش می‌دهد صرفاً بر اساس عملکرد تاریخی و واقعی سیگنال‌های همان سایت محاسبه می‌شود.

== Installation ==

1. پوشه `crypto-signals-pro` را در مسیر `wp-content/plugins/` قرار دهید.
2. افزونه را از بخش «افزونه‌ها» در پیشخوان وردپرس فعال کنید.
3. به منوی «سیگنال کریپتو» بروید و ارزهای مورد نظر، وزن‌دهی تحلیل و متن پیام فروش را تنظیم کنید.
4. برای هر مشتری از بخش «اشتراک کاربران» یک اشتراک فعال (با تاریخ انقضا یا بدون انقضا) ایجاد کنید.
5. کد کوتاه `[crypto_signals]` را در هر برگه یا صفحه‌ای که می‌خواهید گزارش نمایش داده شود قرار دهید.

== Frequently Asked Questions ==

= آیا نیاز به کلید API دارم؟ =
خیر. هسته افزونه با API های رایگان و عمومی Binance و CoinGecko کار می‌کند. فیلدهای کلید API پیشرفته در تنظیمات صرفاً برای اتصال آتی به سرویس‌های اختیاری آن-چین در نظر گرفته شده‌اند.

= آیا نرخ موفقیت ۸۵٪ تضمین می‌شود؟ =
خیر، و هیچ ابزاری در دنیا چنین تضمینی نمی‌تواند بدهد. افزونه به‌جای این ادعا، نرخ موفقیت واقعی و قابل ردیابی سیگنال‌های گذشته‌ی خودش را نمایش می‌دهد.
